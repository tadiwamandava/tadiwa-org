## Small, finished, used

The failure mode of self-directed plans is a graveyard of 80%-done repositories.
This one is deliberately sized to finish: core logic, a scheduling algorithm,
argument parsing, tests, CI, published, done.

It also has to survive the only test that matters for a tool — I have to still be
using it a month later. Everything it schedules is real: every problem I miss
during interview prep goes in, and it tells me when to re-solve it from a blank
file.
