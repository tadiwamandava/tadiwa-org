## The point is the gap

Anyone can reimplement `grep`. The value is in benchmarking it against system
grep and ripgrep on a large corpus, implementing exactly one optimisation,
re-measuring, and reporting the delta, then writing the section titled "why
ripgrep still wins."

Honest gap analysis reads as competence. A benchmark table where your toy
implementation beats the state of the art reads as a methodology error, and an
interviewer will find it.
